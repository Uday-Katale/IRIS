# VALYRIAN AMR Control Center (SIH 2026)

Static single-file dashboard. No build step.

## Deploy
Option A (CLI): `npm i -g vercel` then, inside this folder, `vercel --prod`
Option B (GitHub): push this folder to a repo, import it on vercel.com/new
  - Framework Preset: Other
  - Build Command: (leave empty)
  - Output Directory: (leave empty / ".")
Option C: drag this folder into vercel.com/new

Files: index.html (the dashboard), vercel.json (config)
